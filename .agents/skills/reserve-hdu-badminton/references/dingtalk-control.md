# 钉钉控制流程

## 打开小程序

1. 优先按可访问性文本定位钉钉，不依赖截图中的固定坐标或旧元素编号。
2. 点击左侧导航的“工作台”。
3. 等待工作台 HTML 内容加载，定位“我的”区域第一行的“场馆速约”。
4. 点击“场馆速约”，等待页面出现“个人预约”“团队预约”“用户中心”等文本。

## 强制触发登录

Token 工具已监听后再执行以下操作：

1. 如果当前已经在“场馆速约”，先返回工作台。
2. 重新点击“场馆速约”，触发小程序登录请求。
3. 如果钉钉短暂显示“正在登录”，等待其回到主窗口，再重新进入工作台与小程序。
4. 等待 Token 工具退出，不要通过复制页面内容猜测 Token。

## 失败恢复

- 可访问性树暂时没有工作台内容：重新读取应用状态，等待 HTML 区域加载。
- 文本节点不可点击：点击对应父容器；仍失败时才依据最新截图使用坐标。
- 四分钟内未捕获：退出小程序、回到工作台并重新进入一次。
- 出现证书或网络警告：不要绕过安全警告。先让 Token 工具清理代理；证书状态只能在本机系统级“完全访问”环境复核，不能把受限环境无法读取钥匙串误判为未信任。
- 操作结束后确认 `127.0.0.1:18888` 不再监听；若仍监听，先停止 Token 工具并恢复代理。
